FREEGEMAS

What this is, the controls, and the notices

What you are running

The real Commander X16 build from this repository's x16/hostfs/ — the same boot.prg, loader, overlays, scene chunks, sound effects and music.zcm you would put on an SD card — copied into the emulator's virtual drive and started with -prg boot.prg -run. The emulator is the official X16Community WebAssembly release r49, fetched and checksum-checked when this page is built; it is not vendored in the repository.

Controls (keyboard)

KeysAction
Arrow keysMove the cursor and highlight menu rows
SpaceSelect a gem, then swap with an adjacent gem; confirms a menu item
EnterConfirm the highlighted menu item
HShow a hint / find a possible move
RReset or reshuffle the board
EscReturn from the game to the title
Title ExitQuit to the X16 BASIC READY. prompt

A USB gamepad works too: the D-pad moves, A/B select and swap, Start acts as Enter, Select as Space. The emulator keeps the X16 keyboard layout (en-us), so physical key positions are what the KERNAL sees.

Notes

Audio starts muted; use the “Sound” button (browsers require a click before they allow sound). “Fullscreen” scales the 640×480 VERA screen; “Restart” reloads the page and boots the X16 again. On slower machines the first boot takes a few seconds while the HostFS files are copied into the emulator's memory. High scores are written to the emulator's in-memory filesystem, so they last for this page session only.
